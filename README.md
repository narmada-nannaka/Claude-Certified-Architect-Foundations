# Claude Certified Architect – Foundations: Practice Repo

Each `scenario-XX-*` folder is a self-contained implementation of one exam scenario,
mapped to the domains and task statements in the official exam guide.

## Scenarios
1. Customer Support Resolution Agent — Agent SDK + MCP + escalation
2. Claude Code for Team Dev Workflow — CLAUDE.md, rules, skills, plan mode
3. Multi-Agent Research System — coordinator/subagent orchestration
4. Developer Productivity Tools — built-in tools + MCP integration
5. Claude Code in CI/CD — non-interactive mode, structured output
6. Structured Data Extraction — tool_use schemas, validation, batch API
